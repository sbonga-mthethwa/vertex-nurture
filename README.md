# Vertex Nurture

Vertex Nurture is an AI-powered CRM and customer engagement platform designed to help businesses manage leads, automate follow-ups, nurture customer relationships, and gain actionable insights through intelligent workflows.

## Features

- JWT Authentication
- Refresh Token Rotation
- Role-Based Access Control (RBAC)
- User Management
- REST API (FastAPI)
- PostgreSQL
- SQLAlchemy 2.0
- Alembic Migrations
- Async Architecture
- Structured Logging
